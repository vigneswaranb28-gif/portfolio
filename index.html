Job-Fit Results
Problem

Manually comparing a resume against a job description to judge fit is slow and subjective, especially across multiple roles.

Solution

An agent-driven RAG application ingests a resume and job description, retrieves relevant context, and reasons over both using four purpose-built LangChain tools to produce a structured fit analysis — fully local via Ollama.

Key Features
  • Resume + job description upload
  • Agent-based tool calling (4 custom LangChain tools)
  • Chat-based interactive analysis
  • Local vector storage with ChromaDB
  • Fully local inference via Ollama

Answer
Problem

Finding specific answers inside long PDF documents usually means manually reading through pages of content.

Solution

The application chunks and embeds uploaded PDF content, retrieves the most relevant passages for a user's question, and passes that context to a locally-running open-source LLM to generate a grounded answer.

Key Features
  • PDF upload and processing
  • Chunking + embedding pipeline
  • Context retrieval before generation
  • Local, open-source LLM inference via Ollama
  • Streamlit interface, FastAPI backend
